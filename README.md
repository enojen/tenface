# Tenface

The panel of [tenyard](https://github.com/enojen/tenyard), the Kubernetes-native runtime of
coding agents. It shows, per project, the lanes of the babysitter sessions, the stage of each
task and what waits for you, and it is where you plan the lanes.

Nothing is built yet: [`PRODUCT.md`](PRODUCT.md) holds what the product is.
